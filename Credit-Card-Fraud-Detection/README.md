# Credit Card Fraud Detection

A machine learning project to identify potentially fraudulent credit card transactions using Logistic Regression, Random Forest, and XGBoost.

## Project Status

- [x] Data cleaning and preprocessing
- [x] Model training and evaluation
- [x] Model comparison
- [x] Streamlit web application
- [x] Deployment

## Dataset

[Credit Card Fraud Detection — Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Models

- Logistic Regression
- Random Forest
- XGBoost
