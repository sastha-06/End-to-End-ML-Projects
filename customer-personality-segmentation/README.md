
# Customer Personality Segmentation

An unsupervised machine learning project to segment customers based on their demographics, income, spending patterns, and purchasing behaviour using K-Means and DBSCAN clustering algorithms.

## Project Status

- [x] Data cleaning and preprocessing
- [x] Feature engineering and scaling
- [x] Model training and evaluation
- [x] Model comparison
- [x] Customer segment analysis
- [x] Streamlit web application
- [x] Deployment

## Dataset

[Customer Personality Analysis — Kaggle](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis)

## Models

- K-Means Clustering
- DBSCAN Clustering

## Key Results

- Selected K-Means with **2 clusters** based on the best silhouette score among the tested configurations.
- Identified two customer segments with different income levels, spending habits, and purchasing behaviour.
- Best tested K-Means silhouette score: **0.2001**.
